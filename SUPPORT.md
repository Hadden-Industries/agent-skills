# Support

Agent Skills is maintained by Hadden Industries.
Use the following channels to help route a report without exposing sensitive information.

| Need                                                                      | Channel                                                                                                                                                                       |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installation, usage, or development guidance                              | Start with the [README](README.md), including [troubleshooting](README.md#troubleshooting)                                                                                    |
| Reproducible bug, question, documentation correction, or feature proposal | Search [existing issues](https://github.com/Hadden-Industries/agent-skills/issues), then [open an issue](https://github.com/Hadden-Industries/agent-skills/issues/new/choose) |
| Contributing a change                                                     | Follow [CONTRIBUTING.md](CONTRIBUTING.md)                                                                                                                                     |
| Suspected security vulnerability                                          | Use the private channels in [SECURITY.md](SECURITY.md)                                                                                                                        |
| Community conduct concern                                                 | Use the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)                                                                                                           |
| Privacy concern about information sent to project maintainers             | Follow [PRIVACY.md](PRIVACY.md)                                                                                                                                               |

## What to include in a report

For technical reports, include the skill or tool, exact source commit or installed version, agent host and version, OS, relevant runtime versions, command or prompt, and expected versus actual behavior.
Provide a minimal example with synthetic data and sanitized logs.

Skill-selection problems should identify which skill was expected to activate and what the host actually did.
Static validation, model behavior, and host activation are different observations; describe the evidence you have.

Host-specific installation, account, billing, or model-service problems may need the host or provider's own support channel.
Imported skills and external tools have their own upstream maintainers; identify the component before attributing a failure to this repository.
Public issues provide community and maintainer support without a guaranteed response time or resolution.
